# 🎅 Тайный Санта — Telegram-бот

Бот для игры «Тайный Санта» в группах Telegram. Участники вступают в игру
кнопкой в группе, админ проводит жеребьёвку, а бот присылает каждому в личку
имя получателя и его вишлист.

## Возможности

- Игры в группах: один активный розыгрыш на группу.
- Вступление кнопкой «Участвовать» в группе (deep-link в личку бота).
- Список «моих» групп в личке: только те, где пользователь реально состоит
  и где есть активная игра.
- Вишлист: общий на пользователя, показывается тому, кто дарит подарок.
- Жеребьёвка алгоритмом Саттоло: одна цепочка, без самоподарков.
- Назначения приходят в личку; есть повторная отправка `/resend`.
- Статистика: этап игры и список участников.
- После игры обязателен `/endgame`, только потом можно создать новую.

## Команды

### В группе

| Команда | Кто может | Что делает |
|---|---|---|
| `/newgame` | админ группы | создаёт игру и публикует анонс |
| `/status`, `/stats` | все | этап игры и участники |
| `/draw` | админ группы | проверяет участников и проводит жеребьёвку |
| `/resend` | админ группы | повторно отправляет неотправленные назначения |
| `/cancelgame` | админ группы | отменяет набор участников |
| `/endgame` | админ группы | завершает игру |
| `/help` | все | справка |

### В личке

| Команда | Что делает |
|---|---|
| `/start` | список ваших активных игр |
| `/wishlist` | задать или изменить вишлист |
| `/stats` | список активных игр и статусов |
| `/help` | справка |

## Как проходит игра

1. Админ добавляет бота в группу и выдаёт ему **права администратора**.
2. Админ выполняет `/newgame` — бот публикует анонс с кнопкой «Участвовать».
3. Участник нажимает кнопку → открывается личка бота →
   `/start join_<id>` → бот проверяет членство в группе и добавляет участника.
4. Анонс в группе обновляется (счётчик и список) без спама отдельными
   сообщениями.
5. Админ выполняет `/draw`:
   - проверяет, что участников не меньше 3;
   - заново проверяет, что все ещё состоят в группе;
   - исключает вышедших;
   - проводит жеребьёвку и отправляет назначения в личку.
6. В группу приходит сообщение о старте игры со списком участников.
7. После вручения подарков админ выполняет `/endgame`.

## Почему бот должен быть администратором

Telegram присылает обновления `chat_member` (кто вступил/вышел) только
администраторам чата. Если бот — админ, список «моих групп» работает из
локального кэша без запросов к API. Если прав нет, бот использует
`getChatMember` с кэшем и TTL.

## Оптимизация проверки групп

- Проверяются только группы с активной игрой, а не все чаты.
- `chat_member` обновляет таблицу `chat_members` — обычный `/start` не делает
  ни одного запроса к Telegram.
- Недостающие проверки идут параллельно (`asyncio.gather`) с ограничением
  10 одновременных запросов и ~20 запросов в секунду.
- Положительный результат кэшируется на 24 часа, отрицательный — на 15 минут.
- Кнопка «Участвовать» всегда делает свежую проверку именно этой группы.

## Быстрый старт

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

cp .env.example .env
# впишите BOT_TOKEN из @BotFather

python -m bot.main
```

Токен берётся у [@BotFather](https://t.me/BotFather). Бота нужно добавить в
группу и назначить администратором.

## Docker

```bash
cp .env.example .env
# впишите BOT_TOKEN

docker compose up -d --build
```

SQLite-файл хранится в `./data` (volume). Логи:

```bash
docker compose logs -f
```


## База данных

По умолчанию SQLite: `data/secret_santa.db`. Схема создаётся автоматически
при старте (`Base.metadata.create_all`).

Для перехода на Postgres достаточно поменять `DATABASE_URL` и установить
драйвер:

```
DATABASE_URL=postgresql+asyncpg://user:password@host:5432/secret_santa
```

Модели написаны на SQLAlchemy 2 async, поэтому код менять не нужно.

## Ограничения

- Бот не может получить список групп пользователя — только проверить
  членство в известных ему группах.
- Пользователь должен хотя бы раз нажать `/start`, чтобы бот мог писать ему
  в личку. Deep-link из кнопки делает это автоматически.
- Если участник заблокировал бота, назначение не дойдёт; админ увидит список
  и сможет повторить отправку через `/resend`.
